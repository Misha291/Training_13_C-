# Сумма элементов массива

Консольная программа на C#, которая демонстрирует работу с массивом: вывод всех элементов и вычисление их суммы.

## Описание

Программа содержит заранее объявленный массив целых чисел:
```csharp
int[] numbers = { 3, 7, 2, 9, 4 };
```

Затем с помощью цикла `for` программа:
- Выводит все элементы массива в одной строке;
- Подсчитывает сумму элементов;
- Выводит полученную сумму.

## Использование

1. Запустите программу.
2. Программа автоматически выведет массив и его сумму (никакого ввода от пользователя не требуется).

## Пример вывода

```
Массив: 3 7 2 9 4 
Сумма: 25
```

## Как это работает

- Массив создаётся и инициализируется значениями `{ 3, 7, 2, 9, 4 }`.
- Свойство `numbers.Length` возвращает количество элементов (в данном случае 5).
- Цикл `for` проходит по всем индексам от 0 до `Length - 1`.
- На каждой итерации:
  - Элемент `numbers[i]` выводится на экран;
  - Значение элемента добавляется к переменной `sum`.
- После завершения цикла программа выводит итоговую сумму.

## Требования

- .NET SDK (версия 5.0 или выше) для компиляции и запуска.
- Любая среда разработки, поддерживающая C#.

## Заметки

- Массив фиксирован и задан в коде. Чтобы изменить набор чисел, нужно отредактировать инициализатор массива.
- Программа не обрабатывает ввод пользователя, поэтому дополнительных проверок не требуется.
